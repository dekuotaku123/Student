# Student Attendance Management System

A web-based school management platform designed to simplify student, faculty, class, subject, attendance, and academic record management.

---

## Overview

The Student Attendance Management System provides a centralized platform for managing academic activities within an institution.

The application supports different user roles and provides dedicated functionality for administrators, teachers, and students. It helps streamline attendance tracking, student management, academic performance monitoring, and communication.

---

## Features

### User Roles

The system provides three primary user roles:

- **Administrator**
  - Manage students and teachers
  - Create and manage classes
  - Manage subjects
  - Manage user accounts
  - Oversee the overall system

- **Teacher**
  - Manage assigned classes and subjects
  - Record student attendance
  - View attendance records
  - Enter marks and provide feedback
  - Communicate with students

- **Student**
  - View attendance records
  - Check marks and academic performance
  - Track performance over time
  - View feedback from teachers
  - Communicate with teachers

### Attendance Management

Teachers can record daily attendance for their assigned classes and subjects.

The system maintains attendance records and provides attendance information that can be used to monitor student participation and performance.

### Academic Performance

Teachers can enter student marks and provide feedback.

Students can access their academic records and monitor their performance through organized tables and visual representations.

### Dashboard & Data Visualization

The system provides dashboards that allow users to quickly access relevant academic information.

Students can view their performance through charts and tables, making it easier to understand their academic progress.

### Communication

The platform provides communication functionality between teachers and students, allowing users to exchange information within the system.
